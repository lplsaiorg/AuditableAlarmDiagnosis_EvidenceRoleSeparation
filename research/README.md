# Research implementation

This directory contains the reconstructed benchmark implementation accompanying the revised paper. The original package at the repository root remains the earlier demonstration implementation.

## Setup

Install `requirements.txt` in an isolated Python environment, then run `python prepare_workspace.py`. Obtain the public TEP RData files and HAI 21.03 release separately; place them under `data/TEP` and `data/HAI`. No datasets, model weights, experiment logs, request records, or result bundles are included.

Run scripts from this directory with `python code/<script>.py`. Scripts consume artifacts generated by earlier stages; they are research stages, not independent entry points.

## Implementation map

- `reconstruct.py`, `baselines.py`: initial data preprocessing and baseline artifacts.
- `v2_numeric.py`, `v3_numeric.py`: event features, numerical policies and grouped evaluation.
- `v3_llm.py`, `v2_pollution.py`: matched reader comparisons and historical interventions.
- `v3_audit.py`, `v3_release_gate.py`: evidence checks and optional release gating.
- `v4_tep.py`, `v4_calibration.py`: asymmetric calibration and calibration ablations.
- `v4_hai.py`, `v4_hai_strict.py`, `v4_hai_ablation.py`: HAI feature construction, chronological adaptation and comparisons.
- `review_revision_20261106_v01.py`, `round3_checks_20261106_v01.py`: additional comparisons, paired analyses and matched segment-length checks.
- Analysis, figure and report scripts summarize locally generated outputs.

The numerical route uses current sensor evidence only. Historical cases and generated text enter the explanation branch. The reader is MiniMax-M3.1-Flash; the automated assessor is MiniMax-M3. Supply `MINIMAX_API_KEY`, `MINIMAX_API_KEY_2`, and `MINIMAX_API_KEY_3` through the environment when running API experiments. Each credential has six concurrent slots. New requests do not specify a token limit. API stages incur provider charges and are not part of offline validation.

The scripts retain staged development filenames to preserve their artifact dependencies. Earlier exploratory variants are included for traceability; the final calibration and chronological comparison are identified above. Reproducing reported numbers requires regenerating the data-dependent artifacts and API outputs.
